Contextual agent-actions menu + peek

A shows the same seven rows whatever the group’s state — including “Stop temporary agent…” for agents it can never stop. Build the list from the binding, and add a peek that shows the agent’s last lines without unzooming.

Today’s list for comparison: Choose agent… · Prompt agent… · Check agent status · Reveal thread agent · Hide siblings / zoom Hunk · Stop temporary agent… · Leave unchanged — always, in that order. The first row is highlighted by Hunk, so putting the most likely action first also makes A, Enter do the right thing.

Peek

Herdr can read a pane’s terminal without focusing it. A confirm dialog is the cheapest host surface that fits several lines; “Reveal” as the accept label turns it into a two-step reveal when the peek isn’t enough.

Small related fix

pick should not hold the lock during startup

A → Choose agent calls choose(ctx, thread) with waitForReady = true, so every other Herdr command reports “Herdr operation in progress…” for up to 35 s while a temporary agent boots. P already passes false and follows startup in the background; pick should do the same.
