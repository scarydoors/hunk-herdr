hunk-herdr · UX ideas

Six independently implementable changes that reduce the friction of actually using the extension. Each doc is one idea; two pairs are best landed sequentially rather than in parallel.

01 · highest impact

Shorten the happy path

Seven modals → comment, P, Enter. Auto-assign, DWIM P/A from the cursor, default agent first, empty prompt means “do the comments”.
02 · small, standalone

Pass the session, don’t make the agent find it

A hidden agent that asks “which session?” is a spinner that never ends. The extension already knows the ID.
03 · feedback

Make agent state visible

A sticky “needs attention” row state for blocked/stalled agents, and a Herdr notification when a turn finishes.
04 · pane

Richer Threads pane rows

Agent on the group row, reply counts on comments, select the group you just assigned to.
05 · menu

Contextual agent-actions menu + peek

Build the A menu from the binding’s state; peek at the agent’s last lines without unzooming.
06 · largest

Persist threads and reattach agents

One state file per repo root; rehydrate from the review snapshot; reattach or recognise orphaned temporary agents.
